Ledger — 02The headline finding

API maturity is common. Credential readiness is the real integration frontier.

CRM, productivity, and developer platforms produce the fastest toolkit queue. Ads, financial data, enterprise CRM, and niche AI/media products need a credential or commercial-access conversation before build work starts. 93 of 100 rows expose OAuth somewhere in the primary credential path, but 44 of those are still gated behind a plan, review, or approval step — self-serve OAuth and self-serve access are not the same thing.

Fetch

Live-fetch candidates with 3 attempts and exponential backoff.

03 · extract
Normalize

Normalize auth, access, API/MCP, and explicit evidence claims.

04 · score
Weigh evidence

Favor official docs; hash raw fetches; dedupe canonical URLs.

05 · review
Queue for human

Queue uncertainty, gates, and high-risk claims for evidence checks.

Fallback behavior: the checked-in official-doc registry keeps the demo reproducible if a site blocks automated retrieval. A fallback lowers confidence and never upgrades an unknown API/auth claim. In a production run, preserve retrieved source snapshots and re-run review whenever documentation changes.

Ledger — 06How to reproduce & extend

Run python3 src/research_pipeline.py --mode demo to regenerate this page and machine-readable JSON/CSV. Use --mode live to refresh first-party documentation candidates; review every queue row before treating it as a build commitment. Key limitations: plan and approval policies drift, public docs can omit account-level controls, and an API reference alone does not prove production access.
